# VideoManager

![VideoManager 圖示](assets/videomanager.png)

VideoManager（VM）是一款 Windows 本機影片庫。用縮圖找影片、整理分組與標籤，並直接在程式裡播放、剪輯和壓縮 MP4。影片與個人資料留在自己的電腦。

## 下載

前往 [最新版本](https://github.com/herhtung/VideoManager/releases/latest)，下載 `VideoManager-Setup-0.2.15.exe` 安裝。適用於 Windows 10／11 64 位元。

## 功能

- **瀏覽影片**：網格與清單切換、縮圖輪播預覽、搜尋、排序、篩選，以及影片庫統計。左右側邊欄可收合，資料欄寬可獨立調整。
- **影片詳情浮窗**：停在單部影片或影片組上，查看標籤、關聯與推薦影片；推薦結果包含影片組，可點選跳轉或顯示全部。浮窗可在設定中關閉。
- **整理影片**：標籤分類、評分、收藏、整理狀態與批次管理；影片組也能批次新增或移除標籤與關聯。
- **自訂關聯**：最多三種關聯類別，支援改名、拖曳排序與辨識照片；照片可貼上、裁切、放大或移除，裁切與按鈕統一為橫向比例。長名稱自動省略，滑鼠停留可查看全文。推薦優先採用排在上方的類別。
- **管理多段影片**：將分段建立為影片組，從封面進入分段清單，並可加入、移出或刪除整組。同時查看單部影片數與影片組數。
- **播放影片**：內建播放器支援進度拖曳、空白鍵播放／暫停、F 鍵切換全螢幕與分段接續；音量可調整至 200%，預設為 100%。可從設定選擇預設播放方式。
- **壓縮中心**：試壓縮分析、查看畫質與容量預估、逐部排程、進度與結果比較；可一次確認全部待替換影片。中途關閉程式，可從已完成的壓縮片段接續。待替換工作也能取消，並清除該工作的副本與暫存檔，保留原片。
- **剪輯中心**：選出要保留的片段，先產生副本並確認，再決定是否替換原片。
- **搬入與縮圖進度**：搬入影片、掃描及建立縮圖時，主畫面持續顯示目前進度。
- **影片回收桶**：誤刪影片可先在程式內查看與還原；清空回收桶才會永久刪除。
- **通知中心**：集中查看最近的工作結果與提醒。

影片組、標籤、縮圖、設定及壓縮紀錄都保存在本機。更新程式不會清除影片庫。
