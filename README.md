# VideoManager

![VideoManager 圖示](assets/videomanager.png)

**在 Windows 離線整理 MP4 影片庫。** VideoManager 讓你用縮圖預覽、標籤、搜尋、篩選及內建播放器管理大量影片。既有影片可以保留原位置建立索引；需要交由程式管理的新影片則可搬入指定的影片庫。影片與個人索引不會上傳到雲端。

## 下載與安裝

到 [Releases 頁面](https://github.com/herhtung/VideoManager/releases/latest)下載 `VideoManager-Setup-0.1.0.exe`，執行安裝程式即可。支援 Windows 10／11 64 位元；無須另裝 Python、FFmpeg 或 FFprobe。安裝完成後可從開始功能表啟動，解除安裝不會刪除你的影片庫、資料庫及預覽快取。

這是首個公開測試版，尚未在各種外接硬碟與影片編碼上完成測試。若 Windows 顯示未簽章應用程式警告，請確認檔案來自本專案 Releases，並核對該版本列出的 SHA-256。使用前建議備份重要影片與索引。

## 主要功能

- **快速瀏覽**：影片網格、滑鼠懸停輪播 10／30／60 張影格，支援 5%～90% 等距擷取。
- **整理與搜尋**：可自訂標籤分類、必選標籤、五顆星評分、收藏、備註及多條件篩選；統計頁會顯示數量與比例。
- **多段影片**：多個 MP4 可組成一組，從封面播放、切換分段，並共用標籤與整理資訊。
- **管理檔案**：可選取檔案或拖曳搬入；程式按加入月份分資料夾，每個編號資料夾最多 50 部。刪除影片前會確認，並送到 Windows 資源回收筒。
- **本機保存**：索引、標籤與縮圖位於 `%LOCALAPPDATA%\VideoManager`；外接硬碟暫時離線時仍可瀏覽已建立的資料。

## 開始使用

程式啟動時會最大化視窗。首次開啟可按中央的「設定影片庫根目錄…」，挑選**最外層管理根目錄**，例如 `D:\我的影片庫`。若尚無 `.videomanager/library.json`，程式會先詢問是否建立識別檔。它只存影片庫 UUID，不含標籤或影片內容。**選定根目錄不會掃描整個磁碟或整個根目錄**；使用「加入讀取資料夾」逐一指定需要建立索引的子資料夾，或直接搬入 MP4。程式會讀取自己管理的 `匯入`；舊版已放進 `唯一分類` 的檔案也會繼續讀取，不會自行搬動。影格預覽在背景逐部產生，狀態列顯示進度條及完成部數，可隨時暫停。FFmpeg／FFprobe 已隨程式打包，呼叫時不會跳出命令視窗。下次啟動會用 UUID 辨識影片庫；硬碟代號變更時可手動重新選擇同一個庫。若要保留同一影片庫而整體搬到別處，請搬動**整個根目錄（包含 `.videomanager`）**後重新連接。

若原先選錯根目錄，可用「影片庫 → 重新設定管理根目錄…」或設定視窗的「改用新的空白管理根目錄…」。選擇與原位置分離的**空資料夾**，確認後程式會先備份目前索引，再建立新的管理庫。舊位置的 MP4 不會搬動；之後用「搬入 MP4」分批加入新庫。原索引備份路徑會在完成視窗顯示。

主視窗「搬入方式」預設為「分開搬入」：可選取或拖入多個 MP4，每部各自成片；拖入一個資料夾則遞迴收錄其中 MP4。搬入前會顯示來源與目的地；實體位置依加入月份分為 `根目錄\匯入\YYYY-MM\001`、`002` 等，每個編號資料夾最多 50 部。原檔與目的地在同一磁碟時直接搬移；跨磁碟時先完整複製，再嘗試將來源移到 Windows 資源回收筒。若回收筒不可用，來源會保留並在結果中提示。新加入的影片進「待整理」。

同一部影片若分成多個 MP4，先切到「同組搬入」，再選取或拖入**至少兩個 MP4**，也可選擇或拖入**一個包含多段 MP4 的資料夾**。可直接拖到影片卡片區。程式先按檔名中的數字排序；同組順序只確認一次，接著整組確認來源與目的地，不會逐部跳出確認。確認後，分段會放進以**清理後的第一段檔名**命名的共同資料夾，影片組顯示名稱也使用清理後的第一段名稱；超過 50 段時，組內再分 `001`、`002`。一般清單把單部影片放在上方，影片組放在下方；每組平常只佔一張卡片，封面拼出前幾段的縮圖。按卡片上的「播放」或雙擊可從第一段播放；按「開啟分段」會進入像資料夾一樣的組內清單，各段各有一張卡和段數標記，也可返回清單。影片組卡片右鍵選「修改影片組名稱…」，或進入組內按「修改組名」，卡片與左側清單會立即更新；此操作只改顯示名稱，不搬動 MP4 或資料夾。左側同樣有影片組入口，播放器播完會接下一段，也可按上一段／下一段。組內共用標籤。已在庫內的多段也可 Ctrl／Shift 選取後用「將所選影片建立為一組」；若背景縮圖正在載入，程式會先暫停再顯示同組確認。

## 主要操作

- 左側可切換待整理、整理中、全部、已整理、收藏、待清理、標籤、影片組與已存篩選。中央搜尋、排序、篩選及清單／網格切換；Ctrl 或 Shift 多選後可批次加／移除標籤。
- 搜尋列可按「搜尋」或 Enter 套用；輸入框內的叉號可立即清除搜尋文字。「清除條件」會同時清除搜尋文字、進階篩選，並切回全部影片；篩選按鈕會顯示目前條件數。進階篩選視窗也有「清空條件」。
- 主視窗「統計」可查看影片總數、總容量、總片長、影片組、收藏與整理進度。各標籤依分類列出影片數，例如「7 / 500 部」，旁邊有細比例線並可搜尋。統計直接讀取本機索引，同組的每個 MP4 分段各算一部。
- 右側編輯顯示名稱、標籤、五顆星評分、備註等。沒有選取影片時右欄仍固定顯示，但內容清空並停用；點清單空白處會取消選取。標籤依「標籤分類」收合成按鈕，可搜尋、捲動；旁邊「＋」可直接新增並選取，按儲存套用。按「儲存」會寫入資料並把待整理影片改為「整理中」；按「完成整理」還會標記為「已整理」，主清單會接著選下一部。已整理或整理中的影片可按右側「退回待整理」，保留原有資料；Ctrl／Shift 多選後也可從「編輯」選單或右鍵選單批次退回。右鍵影片也能快速播放、管理標籤、建立同組、重建影格和刪除。雙擊影片開內建播放器，預設最大化；可用 Windows 標題列縮放按鈕，右側資訊欄預設收起，按「顯示資訊」會浮在影片右側。資訊欄的修改在關閉播放器時會儲存並更新外面的右欄。影片讀取期間會顯示提示，背景縮圖解碼會立即暫停讓出資源。時間線加厚、按鈕縮矮；進度條可點擊跳轉，也可拖曳；左右鍵各跳 10 秒，上下鍵各調音量 5%。可按「全螢幕播放」並用 Esc 退出。播放失敗可按「以 Windows 預設播放器開啟」。
- 「設定 → 影片庫位置、預覽模式與速度…」可選 **標準 10 張、詳細 30 張、高密度 60 張**，並調整懸停等待、輪播速度與縮圖大小。每種模式都在片長 **5%～90%** 等距擷取。切換密度後會在背景重建快取；滑鼠離開卡片或移到空白處即停止輪播並回到封面。「影片庫」與「設定」選單都有「匯入檔名清理…」，可逐條新增、修改或確認刪除要移除的字句；設定頁也提供相同的逐條編輯器。按「儲存並掃描現有影片…」可預覽已建檔 MP4 的原檔名與清理後檔名，確認後才逐部改名；已存在的影片組名稱也會列入預覽，確認後只更新組名，不搬動組資料夾。同名衝突或檔案已變更會略過，不覆蓋原檔，標籤與自訂顯示名稱保留。新影片搬入前會預覽清理後的目的檔名，重名自動加編號，現有影片不受影響。
- 「管理標籤…」以可搜尋、可收合的按鈕清單管理標籤；標籤分類直接逐行顯示，不用下拉選單。可新增、改名、調色、合併標籤，也可選既有標籤和目標分類後按「移到所選分類」，原有影片關聯不變。每個標籤分類都能自行設定「完成整理時必選」；開啟後，完成整理前須從該分類至少選一個標籤，一般儲存不受限制。「進階篩選…」先顯示標籤 AND／OR／NOT 按鈕，下方才是時間、片長、大小、解析度、評分與收藏等條件。可把條件存成「已存篩選」；它會隨影片資料變動自動更新結果，不建立實體資料夾。舊版分類關聯升級時會轉為標籤，原始 MP4 位置維持不變。
- 「管理標籤與標籤分類」視窗加大到 1260 × 820；左側分類標題與標籤按鈕都可直接拖曳排序，標籤也可拖到左側其他分類；右側分類列表仍可拖曳排序。原本的上移、下移及「移到所選分類」按鈕仍可使用。
- 點選影片組外層卡片或進入分段畫面時，右側編輯欄仍可編輯整組。組名在外層編輯，分段顯示名稱仍各自獨立；標籤、評分、收藏、拍攝日期、備註與整理狀態在外層或任一分段儲存後會同步到整組。整組亦可用右鍵退回待整理。影片清單更新時保留選取項目和捲動位置。
- 「影片庫」選單可重新掃描、繼續／暫停縮圖載入、建立庫內資料夾、匯出／還原資料庫備份及確認清理待清理記錄。暫停載入不會停用已完成的縮圖。主視窗操作列最右邊的「刪除選取」支援 Ctrl／Shift 多選，先列出所選 MP4 路徑供確認，再逐部送至 Windows 資源回收筒；同組只處理選取的分段，不會永久刪除。「編輯」選單也保留這個入口，並提供改名／移動單部 MP4、重建影格。改名與移動限已驗證的影片庫根目錄內，目的地已存在時會拒絕覆蓋。

主視窗也直接提供分開／同組搬入切換、掃描、預覽、讀取資料夾與標籤操作。預覽影格會在原縮圖位置輪播；若單一擷取時間點失敗，會用鄰近的成功影格補齊，舊版單張失敗的工作會自動重試一次，影片右鍵也可手動「重新產生影格」。從 10 張切到 30 或 60 張時，舊封面會保留到新影格完成。

影片庫離線時仍可瀏覽本機索引、標籤、備註與既有預覽；播放及檔案操作需要重新連接。掃描失敗或取消不會把未掃到的影片判為遺失。完整掃描確認消失的影片會進「待清理」；自動清理需至少七天並重新完整掃描，手動清理會先再次確認。

## 從原始碼執行

需要 Windows、Python 3.12+、FFmpeg 與 FFprobe 在 `PATH`。在 PowerShell 執行：

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -e .
.venv\Scripts\python -m videomanager
```

可用 `--data-dir C:\Path\To\DisposableData` 指定隔離的本機資料目錄。正式使用預設 C 槽資料目錄。第一次試用建議產生可拋棄測試庫：

```powershell
.venv\Scripts\python scripts\make_test_library.py "$env:TEMP\VideoManager-Test-Library"
.venv\Scripts\python -m videomanager --data-dir "$env:TEMP\VideoManager-Test-Data"
```

產生器拒絕覆寫既有目的目錄。測試與開發過程只對可拋棄測試片執行實體改名、移動和回收筒操作。

## 測試與打包

```powershell
.venv\Scripts\python -m unittest discover -s tests -v
$env:QT_QPA_PLATFORM = 'offscreen'
.venv\Scripts\python scripts\smoke_full_ui.py
.venv\Scripts\python scripts\smoke_group_ui.py
.venv\Scripts\python scripts\smoke_import_ui.py
.venv\Scripts\python scripts\stress_ui.py
.venv\Scripts\python -m pip install pyinstaller
.\packaging\build_windows.ps1 -Python (Resolve-Path .venv\Scripts\python.exe).Path
```

打包腳本採 PyInstaller onedir。公開發行時使用 `-FfmpegDir` 指向對應的 LGPL shared 組建資料夾，再以 [Inno Setup 腳本](packaging/VideoManager.iss) 建立安裝檔；不指定時則採目前 `PATH` 中的 FFmpeg／FFprobe，僅適合本機測試。使用的第三方元件與來源見 [第三方元件說明](packaging/THIRD_PARTY.md)。
