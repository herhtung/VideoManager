# VideoManager

![VideoManager 圖示](assets/videomanager.png)

VideoManager（VM）是一款 Windows 本機影片庫。用縮圖找影片、整理分組與標籤，並直接在程式裡播放、剪輯和壓縮 MP4。影片與個人資料留在自己的電腦。

## 下載

前往 [最新版本](https://github.com/herhtung/VideoManager/releases/latest)，下載 `VideoManager-Setup-0.2.12.exe` 安裝。適用於 Windows 10／11 64 位元。

## 功能

- **瀏覽影片**：網格與清單切換、縮圖預覽、搜尋、排序、篩選，以及影片庫統計。
- **整理影片**：標籤分類、評分、收藏、備註、整理狀態與批次管理；可依條件儲存常用篩選。
- **管理多段影片**：將分段建立為影片組，從封面進入分段清單，並可加入、移出或刪除整組。
- **播放影片**：內建播放器支援進度拖曳、鍵盤控制、全螢幕與分段接續；可從設定選擇預設播放方式。
- **壓縮中心**：試壓縮分析、查看畫質與容量預估、逐部排程、進度與結果比較；確認後才替換原片。中途關閉程式，可從已完成的壓縮片段接續。
- **剪輯中心**：選出要保留的片段，先產生副本並確認，再決定是否替換原片。
- **搬入與縮圖進度**：搬入影片、掃描及建立縮圖時，主畫面持續顯示目前進度。
- **程式回收桶**：誤刪影片可先在程式內查看與還原；清空回收桶才會永久刪除。
- **通知中心**：集中查看最近的工作結果與提醒。

影片組、標籤、縮圖、設定及壓縮紀錄都保存在本機。更新程式不會清除影片庫。
